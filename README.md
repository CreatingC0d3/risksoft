## 🚀 Características Principales
- **Gestión de Equipos:**
  - Registro de nuevos equipos
  - Autenticación segura
  - Listado de equipos registrados

- **Elementos de Escalada:**
  - Registro de elementos con parámetros calóricos y de peso
  - Validación en tiempo real de límites
  - Histórico de elementos por equipo

- **Búsquedas Avanzadas:**
  - Consulta por nombre de equipo
  - Cálculos acumulativos de peso y calorías
  - Visualización detallada de elementos
